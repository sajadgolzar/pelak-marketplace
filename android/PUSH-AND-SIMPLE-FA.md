# پلاک — نسخه ساده وب و اندروید + اعلان بومی (۲۰ آبان ۱۴۰۵)

## ۱. نسخه ساده و قابل آزمایش
- وب کلاسیک و اصلی: https://pelakauto.com/
- طرح ساده و مستقل: https://pelakauto.com/?simple=1
- در طرح ساده دکمه «نمای کلاسیک» برای بازگشت وجود دارد.
- نسخه اندروید v0.2 همیشه طرح ساده را باز می‌کند؛ تمام آگهی‌ها، ورود، پیام‌ها و مدیریت از سایت اصلی و Supabase موجود استفاده می‌کنند.
- **مهم:** هیچ جدول اصلی خودرو، عکس یا نقش مدیریتی توسط این طرح تغییر نکرده است.

## ۲. اعلان بومی اندروید — قبل از فعال‌سازی باید این مراحل تکمیل شوند
اپ v0.2 کد Firebase Messaging و کانال اعلان دارد، اما بدون پیکربندی Firebase فعال نیست.

الف) Firebase Console → ایجاد پروژه PELAK و افزودن Android App با شناسه:
\`com.pelakauto.app\`

ب) از تنظیمات همین اپ در Firebase فایل google-services.json را **صرفاً برای خواندن شناسه‌ها** بگیر. این فایل را در GitHub یا چت منتشر نکن. مقادیر زیر را در GitHub → Settings → Secrets and variables → Actions اضافه کن:

- \`PELAK_FIREBASE_APP_ID\` ← \`mobilesdk_app_id\`
- \`PELAK_FIREBASE_API_KEY\` ← \`current_key\` در بخش \`api_key\`
- \`PELAK_FIREBASE_SENDER_ID\` ← \`project_number\`
- \`PELAK_FIREBASE_PROJECT_ID\` ← \`project_id\`

این چهار مقدار، شناسه‌های کلاینت Firebase هستند، نه کلید خصوصی سرور. به‌صورت BuildConfig در APK قرار می‌گیرند.

ج) فایل SQL زیر را فقط پس از بررسی در Supabase SQL Editor اجرا کن:
\`supabase/pelak-android-push-20261110.sql\`
این SQL جدول خصوصی توکن، صف اعلان و Triggerهای جدید را اضافه می‌کند؛ اعلان‌های وب فعلی را تغییر نمی‌دهد.

د) در Firebase Console → Project Settings → Service accounts یک Service Account مخصوص ارسال FCM بساز. محتوای JSON کلید خصوصی را **فقط** در Secrets مربوط به Supabase Edge Function با نام
\`PELAK_FIREBASE_SERVICE_ACCOUNT_JSON\` نگه دار. این کلید را هرگز در GitHub، فایل‌های سایت، APK یا چت قرار نده.

ه) در Supabase Edge Functions، تابع زیر را deploy کن:
\`supabase/functions/pelak-android-dispatch/index.ts\`
و این متغیرها را در تنظیمات Secret فراهم کن:
- \`PELAK_FIREBASE_SERVICE_ACCOUNT_JSON\`
- \`PELAK_FIREBASE_PROJECT_ID\`
- \`PELAK_ANDROID_PUSH_JOB_SECRET\` (یک مقدار تصادفی محرمانه برای اجرای کار زمان‌بندی‌شده)
- \`SUPABASE_URL\` و \`SUPABASE_SERVICE_ROLE_KEY\` (متغیرهای سمت سرور Supabase؛ نباید در کلاینت باشند)

زمان‌بندی ارسال هر یک دقیقه باید از طریق یک Cron امن در Supabase تنظیم شود که Edge Function را با
\`Authorization: Bearer <PELAK_ANDROID_PUSH_JOB_SECRET>\`
فراخوانی کند. اجرای این مرحله *هنوز خودکار نشده است*؛ بدون آن توکن و رویداد ذخیره می‌شوند ولی اعلان ارسال نمی‌شود.

و) پس از تنظیم چهار Secret گیت‌هاب، یک Build APK جدید بگیر و روی گوشی واقعی Android نصب کن. وارد پلاک شو و «🔔 اعلان‌های اپ» را فعال کن.

## ۳. چه اعلان‌هایی طراحی شده‌اند؟
- آگهی برگشتی و نیازمند اصلاح
- تأیید و انتشار آگهی
- دریافت گزارش تخلف توسط مدیر اصلی
- رخدادهای قابل دریافت از \`pelak_push_events\` مثل پیام‌های پشتیبانی یا آگهی‌ها، بسته به Triggerهای نصب‌شده فعلی

## ۵. محدودیت‌ها
- این APK برای آزمون است، نه نسخه امضاشده قابل انتشار در فروشگاه.
- وب فعلی پیش‌فرض باقی می‌ماند تا مالک نسخه ساده را تأیید کند.
- ظاهر و جریان‌های کلیدی از تجربهٔ اپ‌های آگهی الهام گرفته‌اند، اما کد، برند، رنگ و اطلاعات پلاک مستقل‌اند.
- دریافت اعلان بستگی به مجوز اندروید، سرویس‌های Google Play، اینترنت و سلامت Firebase دارد.
